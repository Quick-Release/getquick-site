# {{project}}

{{project}} is a GETQUICK content site. This is its glossary: the terms its
code, docs and agents use, each defined once. Add a term when a discussion
settles what it means; record a decision about it in `docs/adr/`.

## Language

**Site**:
{{project}}'s own repository, CMS, Frontend, and data.

**CMS**:
The site's Bedrock WordPress editorial backend and WPGraphQL API, deployed to
Ploi.

**Frontend**:
The site's public website, rendered from the CMS's content and deployed to
Cloudflare Workers.

The blueprint and fleet vocabulary (blueprint, managed file, site-owned file,
variant) is
[getquick-site's glossary](https://github.com/Quick-Release/getquick-site/blob/main/GLOSSARY.md).
