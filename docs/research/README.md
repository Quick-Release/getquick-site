# Research

Investigation write-ups that inform a later decision but aren't themselves
one — spike results, options considered, trade-off analysis, API
inventories. One kebab-case Markdown file per topic.

If a piece of research leads to a durable decision, record that decision as
an [ADR](../adr/) and link back to the research doc, rather than duplicating
the reasoning in both places.
